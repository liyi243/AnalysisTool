## 6. 已知限制

1. 未知 Fn 数据单元以 HEX 兜底（标准 6.5 节 Fn 数据单元众多，常用项已内置，其余按 `applayer._DECODERS` 注册扩展）；
2. DL/T 698.45 内嵌报文暂做 HEX 展示（后续版本可挂接 698 解析器）；
3. MAC 地址按帧内字节序展示，厂家显示习惯差异已在调研笔记 §8 登记待核对；
4. 通信方式 4=双模(HDC) 依据 2024 版开源实现注释，标注"待确认"。
