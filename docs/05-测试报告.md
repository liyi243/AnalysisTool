## 5. 闪退排查结论（用户报告）

| 措施 | 说明 |
|---|---|
| 根因分析 | `--windowed` 打包下未捕获异常被吞掉、进程直接退出且无痕迹；本次冒烟复现的同类缺陷（QTreeWidgetItem 构造 + Session 不可哈希）已修复 |
| 全局异常钩子 | `main.py` 安装 `sys.excepthook`：异常写入 `logs/crash-YYYYMMDD.log` 并弹窗展示详情，再次闪退可直接提供日志定位 |
| 单帧降级保护 | 管线对 `parse_frame` 逐帧 try/except，单帧内部异常降级为 HEX 展示，不拖垮整批解析 |

## 6. 已知限制

1. 未知 Fn 数据单元以 HEX 兜底（在 `applayer._DECODERS` 注册扩展即可）；
2. DL/T 698.45 内嵌报文暂做 HEX 展示；
3. 03-F10 布局探测基于 41B（华立）/42B（标准）互斥判断，其他厂商固件若引入第三种布局需扩展探测规则；
4. 组帧流程归类基于华立 V2.3 文档 + 附录 A 规则表，未匹配的 AFN/Fn 归入"其他/未归类"。
