# 376.2 协议解析工具 — UI 设计说明书

| 文档版本 | V1.0 | 编写日期 | 2026-11-16 |
|---|---|---|---|

## 1. 设计原则

1. **专业感优先**：面向协议工程师，视觉风格参考 Wireshark/现代 IDE 的深色工作台，信息密度高但不拥挤；
2. **一眼看懂一帧**：字节映射图按字段着色 + 颜色图例 + 悬停解释，把"逐字节比对"变成"看色块"；
3. **单窗口闭环**：输入→解析→浏览→导出，全程不弹二级窗口（导出除外）；
4. **克制**：无装饰性渐变滥用、无动效干扰；圆角、间距、字号遵循统一规格。

### 2.4 几何规格

- 分隔线 1px `#23304A`。

## 3. 布局设计

### 3.1 整体布局（主窗口 1440×900，最小 1180×700）

```
┌──────────────────────────────────────────────────────────────────────┐
│  ◇ 376.2 协议解析工具                    协议: QGDW 376.2 ▾  [关于 ⓘ] │  顶栏 h48
├───────────────┬──────────────────────────────────────────────────────┤
│ ◈ 输入        │  ◈ 帧列表                                    [导出▾] │
│ ┌───────────┐ │  ┌──────────────────────────────────────────────────┐│
│ │[单帧][多帧]│ │  │ #  方向   长度  控制码 功能   AFN  摘要      校验  ││
│ │[文件]     │ │  │ 1  ↓下行   43    0B   读数据  0C  中继抄读...  ✓   ││
│ │           │ │  │ 2  ↑上行   96    8B   读响应  0D  中继数据...  ✓   ││
│ │ hex编辑器  │ │  └──────────────────────────────────────────────────┘│
│ │ (等宽字体) │ │  ◈ 字节映射          ◈ 字段树                        │

│ │           │ │  │ 0000  68 25 00 68 0B 33 …  ││ ▸ 链路层            ││
│ │[示例▾][清空]│ │  │ 0010  33 33 33 33 8C 90 … ││   ▸ 起始符 68H     ││
│ │[▶ 解析]   │ │  │ ■ ■ ■ ■ 图例…             ││   ▸ 控制码C …       ││
│ │           │ │  └───────────────────────────┘└─────────────────────┘│
│ │ ◈ 解析要点 │ │  ◈ 解析要点 / 诊断                                    │
```

- 左侧输入面板固定宽 **360px**；右侧为垂直三段：帧列表（可折叠，单帧时自动收起）、中部水平分割（字节映射 60% / 字段树 40%）、解析要点卡片；
- 所有分割条可拖拽记忆布局（QSplitter）。

### 3.2 输入面板（左侧）

| 元素 | 规格 |
|---|---|
| 模式切换 | 分段控件（Segmented）三档：单帧 / 多帧 / 文件，选中态 accent 底色 |
| hex 编辑器 | `QPlainTextEdit` 等宽字体，占位符"粘贴 68…16 报文，支持空格/换行/注释"；多帧模式显示字节数与检测帧数实时提示 |
| 文件模式 | 拖拽区 + [浏览…] 按钮，支持 `.txt .log .hex .csv .bin .dat`，显示文件名/大小 |
| 操作行 | [示例 ▾]（下拉样例库）/ [规范化]（去注释时间戳）/ [清空]；主按钮 [▶ 解析 Ctrl+Enter] accent 实底 |
| 实时统计 | 编辑器下方胶囊：`3 帧 · 86 字节`，检测到疑似异常时黄色告警胶囊 |
| 解析要点卡 | 当前选中帧的一句话摘要 + 错误告警列表（若有） |

### 3.3 帧列表（表格）

| 列 | 内容 | 样式 |
|---|---|---|
| # | 序号 | muted |
| 方向 | ↓下行 / ↑上行 胶囊徽章 | 下行=violet、上行=success，胶囊全圆角 |
| 长度 | 帧总字节数 | 等宽 |
| 控制码 | `41` | 等宽 + DIR/PRM/通信方式摘要 |
| AFN | `0C` + 名称 | 等宽 |
| 摘要 | 应用层一句话（如"中继抄读 表号 201012030045"） | 主文本色 |
| 校验 | ✓ 通过 / ✗ 失败 | success / error |

- 选中行 accent 左边条 + 行高亮；双击行 = 在字节映射图中展开该帧；
- 异常帧"校验"列显示 ✗，摘要显示失败原因缩略。

### 3.4 字节映射图（自绘控件 HexByteMapViewer）

- 顶部偏移标尺（每 16 字节一行，行首 4 位 hex 偏移）；
- 字节以 2 位 hex 呈现，按所属字段着色（2.2 配色），字段整段共享底色条；
- 行尾 ASCII 列（可开关，默认开）：可打印字符显示，否则 `·`；
- 悬停：tooltip 显示"字段名 · 偏移 0x07 · 原始 0x33 · 含义…"；点击：字段树定位并展开对应节点；
- 底部图例（色块+字段名），仅显示当前帧实际包含的字段；
- 校验失败时，相关字节红色描边闪烁提示（一次性动画，不循环）。

### 3.5 字段树

- 列：字段 / 偏移 / 原始值 / 解析值；
- 层级：帧 → 链路层（起始符/长度/控制域[位分解子节点]/信息域R[位分解子节点]/地址域/…）→ 应用层（AFN/DT/数据单元…）→ 内嵌 645 帧（若数据转发/并发抄表）；
- bit 级解析（控制码 D7 传输方向、D6 从动标志…）以子节点缩进呈现；
- 颜色语义与字节图一致；错误节点行底色淡红。

### 3.6 状态栏

`就绪 | 帧总数 N（上行 x / 下行 y）| 校验失败 z | 输入 xx 字节 | v1.0.0`，解析中显示"解析中…"，完成显示耗时。

## 4. 交互流程

### 4.1 主流程（单帧）
```
粘贴hex → [▶解析] → 帧列表1行自动选中 → 字节映射着色 + 字段树展开至二级
        → 解析要点显示摘要；无错误时状态栏绿色"解析成功 · 耗时 xx ms"
```

### 4.2 多帧/文件
```
输入/选文件 → 解析 → 帧列表N行（异常帧标红）→ 单击行切换详情
→ [导出▾]：JSON报告 / TXT报告 / 复制全部解析文本
```

### 4.3 快捷键
| 键 | 动作 |
|---|---|
| Ctrl+Enter | 解析 |
| Ctrl+L | 清空 |
| Ctrl+E | 导出菜单 |
| Ctrl+1/2/3 | 切换 单帧/多帧/文件 模式 |
| ↑/↓（帧列表聚焦时） | 帧切换 |

## 5. 组件视觉规格（QSS 要点）

- 主按钮：`accent` 实底、白字、hover 提亮、pressed 下沉 1px；禁用 40% 透明；
- 次按钮：透明底 + 1px `border` 描边，hover 背景 `bg-panel-2`；
- 输入框：`bg-panel-2` 底、聚焦时 1px accent 外发光（`border: 1px solid #3B82F6`）；
- 表格：表头 `bg-panel` 加粗小写字距 0.5px；行高 34px；交替行 `#0F1830`；
- 滚动条：8px 圆角，滑块 `#334155`，hover `#475569`；
- Tab（输入模式分段控件）：胶囊分段，选中 accent 底白字；
- 菜单/下拉：`bg-panel-2` 圆角 8px 阴影，item hover accent 10% 底色。

## 6. 状态与反馈

| 场景 | 反馈 |
|---|---|
| 解析成功 | 状态栏 success 文案 + 帧列表刷新，字节图动画淡入（120ms） |
| 未检测到帧 | 输入框下方 warning 胶囊"未检测到 68…16 帧"，编辑器红框 800ms |
| 校验失败帧 | 帧列表 ✗、字节图红色描边、诊断卡说明原因与偏移 |
| 大文件 | 解析按钮变"解析中…"禁用；完成后恢复（预留后台线程） |
| 空输入解析 | 行内提示，不打断 |
