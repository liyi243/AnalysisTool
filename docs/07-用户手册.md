# 376.2 协议解析工具 — 用户手册

## 1. 启动

- **可执行文件**：双击 `dist/376.2协议解析工具/376.2协议解析工具.exe`（免安装）。
- **源码运行**：`python src/main.py`。
- 启动后自动载入一条样例帧（链路检测）并完成首次解析，便于快速了解界面。

## 2. 三种输入模式

| 模式 | 用法 |
|---|---|
| **单帧** | 粘贴一帧 hex → 点击「▶ 解析」或 Ctrl+Enter。自动忽略空格/换行/注释/时间戳 |
| **多帧** | 粘贴连续字节流（可含噪声、粘包、多帧混发）→ 解析，帧列表逐帧展示 |
| **文件** | 将 `.txt/.log/.hex/.csv/.bin/.dat` 拖入窗口（或点击浏览）→ 自动提取帧并解析。支持带时间戳、中文注释的串口日志 |

输入格式兼容：`68 10`、`68-10`、`68,10`、`68H 10H`、`0x68 0x10`、`6810` 连续写法。
「规范化」按钮可将任意输入整理为标准的大写空格分隔形式。

## 3. 解读结果

1. **帧列表**：每帧一行，显示方向徽章（↓下行紫 / ↑上行绿）、长度、控制码、通信方式、AFN、摘要、校验状态（✓/✗）。单击任意行切换详情；
2. **字节映射图**：按字段语义着色（起始符灰/长度紫/控制域琥珀/信息域青/地址天蓝/AFN绿/数据蓝/内嵌645粉/CS玫红/异常红框）。**悬停**查看字段含义，**点击**定位字段树；
3. **字段树**：字段/偏移/原始值/解析值 三级展开；控制域 DIR/PRM/通信方式、信息域各位、地址域 A1/A2/A3、DT→Fn、内嵌 645 帧逐项解读；点击树节点可反向高亮字节图；
4. **解析要点/诊断**：当前帧摘要与错误原因（如"CS 校验失败：计算 0x45 ≠ 帧内 0x46"）。

## 4. 内置示例

## 6. 快捷键

| 键 | 功能 |
|---|---|
| Ctrl+Enter | 解析 |
| Ctrl+L | 清空 |
| Ctrl+1 / 2 / 3 | 切换 单帧/多帧/文件 模式 |

## 7. 常见问题

| 现象 | 说明 |
|---|---|
| 提示"疑似 376.1 帧" | 输入流符合 376.1（双起始符）特征。本工具面向 376.2，请确认报文来源 |
| 校验列 ✗ | 查看诊断区具体原因（CS 不符给出计算值与帧内值）；字节图中出错字节带红框 |
| 未知 AFN/Fn 显示"备用/未定义" | 该编码不在标准表内，工具不臆造含义 |
| 数据单元显示 HEX | 该 Fn 格式暂未内置逐字段解析，可对照标准查阅（扩展方法见 03 设计文档 §8） |
| 帧体不完整 | 输入流末尾的帧未收全，检查采集是否中断 |

## 8. 协议口径说明

解析依据 Q/GDW 10376.2—2019（代替 1376.2-2013）：**单起始符 68H、长度域=整帧总长（2 字节小端）、CS=控制域起至数据末累加和**。376.2 与 376.1 帧结构差异较大（详见 docs/03 §7），请勿混用资料。
