# 376.2 协议解析工具 — 构建与发布说明

| 文档版本 | V1.0 | 编写日期 | 2026-11-16 |
|---|---|---|---|

## 1. 构建环境

| 项 | 值 |
|---|---|
| 操作系统 | Windows 10/11 x64 |
| Python | 3.12.10（`D:/workspace/devEnvironment/python`） |
| GUI | PySide6-Essentials 6.12.0 |
| 打包 | PyInstaller 6.22.3 |
| 注意 | 本机 `python` 命令被 WindowsApps 占位符遮蔽，脚本内统一使用绝对路径 |

## 2. 一键打包

```bat
scripts\build_exe.bat
```

脚本执行三步：

1. `python src\main.py --selftest` — 内置样例自测，失败即终止；
2. PyInstaller onedir 打包（`--windowed --paths src`，入口 `src/main.py`）；
3. 输出产物 `dist\376.2协议解析工具\376.2协议解析工具.exe`。

## 3. 产物说明

| 项 | 值 |
|---|---|
| 形态 | onedir 目录（启动快、误报率低） |
| 大小 | 见 5 节验证结果 |
| 运行依赖 | 无（Qt 运行时已随包携带） |
| 命令行自测 | `376.2协议解析工具.exe --selftest` |

## 4. 手动打包命令（备查）

```bash
D:/workspace/devEnvironment/python/python.exe -m PyInstaller --noconfirm --clean \
    --name "376.2协议解析工具" --windowed --paths src \
    --icon resources/icon.ico \
    --distpath dist --workpath build src/main.py
```

## 5.1 打包形态说明

| 项 | 值 |
|---|---|
| 方式 | PyInstaller 6.22.3 + `3762tool.spec`（UTF-8 spec，规避 cmd 中文乱码） |

## 6. 常见问题

| 问题 | 处理 |
|---|---|
| 杀软误报 | onedir 形态 + 本地签名可缓解；将 dist 目录加入白名单 |
| 启动无界面 | 用 `--selftest` 先验证引擎；确认 exe 与 dist 内目录完整 |
| 中文乱码 | 系统需包含中文字体（Windows 自带微软雅黑） |
