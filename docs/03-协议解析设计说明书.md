# 376.2 协议解析设计说明书

| 文档版本 | V1.0 | 编写日期 | 2026-11-17 |
|---|---|---|---|

**协议依据**：Q/GDW 10376.2—2019《用电信息采集系统通信协议 第2部分：集中器本地通信模块接口》（代替 Q/GDW 1376.2—2013，帧格式在 2013→2019 之间未变）。本文全部结论经标准原文 + 四套独立开源实现交叉验证，并附 29 条 CS 验证通过的示例帧（详见 `resources/research/链路层帧格式调研.md`）。

## 1. 帧结构总览

```
68H │ L(2字节,小端) │ C │ 信息域R(6B) │ 地址域A(条件出现) │ AFN │ DT(2B) │ 数据单元 │ CS │ 16H
```

| 字段 | 长度 | 说明 |
|---|---|---|
| 起始符 | 1 | 固定 68H。**只有一个起始符**（与 376.1 的 `68 L L 68` 双起始符不同） |
| 长度域 L | 2 | BIN 小端。**L = 整帧总字节数 = L1 + 6**（固定 6 字节 = 68H(1)+L(2)+C(1)+CS(1)+16H(1)；L1 = R+A+AFN+DT+数据单元）。无标志位，≤65535 |
| 控制域 C | 1 | **D7=DIR**（0=集中器下行，1=模块上行）；**D6=PRM**（1=启动站，0=从动站）；**D5~D0=通信方式**（1=集中式路由载波，2=分布式路由载波，3=HPLC[2019]/宽带载波[2013]，4=双模HDC[2024，待确认]，10=微功率无线，20=以太网）。**无功能码** |
| 信息域 R | 6 | 上下行位定义不同（见 §3），第 6 字节为报文序列号（配对请求/应答） |
| 地址域 A | 0/12/18… | **R1.D2 通信模块标识=1 时才存在**。A1 源地址(6B BCD) + A2 中继地址(仅下行，6B×中继级别) + A3 目的地址(6B BCD)。广播 A3=999999999999H。地址为本地通信网主/从节点 12 位 MAC |
| AFN | 1 | 应用功能码（§4） |
| 数据单元标识 DT | 2 | DT1（信息类元，位掩码）+ DT2（信息类组，BIN）。**Fn = DT2×8 + DT1 置位位序号 k（k=1..8）**；DT1 可多位同时置 1（一帧多 Fn） |
| 数据单元 | 变长 | 按 AFN/Fn 定义（§5） |
| 校验和 CS | 1 | **CS = 控制域 C 起至最后数据字节的算术和 mod 256**（不含 68H/L/CS/16H） |
| 结束符 | 1 | 固定 16H |

最小合法帧 15 字节（L=0FH，无地址域、数据单元为空）。

## 2. 分帧扫描算法（scanner.py）

```text
i ← 0
while i < n:
    if data[i] ≠ 68H: i += 1; continue
    L ← data[i+1] | data[i+2]<<8          # 小端
    if L < 15 或 L > 65535: i += 1; continue
    if data[i+3..4] == data[i+1..2] 且 L&0x03==2 且 376.1 形态自洽:
        记录告警"疑似 376.1 帧"；i += 1; continue   # 长度域重复+低2位=10B 是 376.1 特征
    end ← i + L                            # L=总长，帧体为 data[i : i+L]
    if end > n: 记录"帧体不完整"告警；i += 1; continue
    if data[end-1] ≠ 16H: i += 1; continue
    calc ← sum(data[i+3 : end-2]) & 0xFF   # C 起至数据末
    if calc == data[end-2]: 输出有效帧；i ← end（粘包自动续扫）
    else: 输出异常帧（记录 CS 计算值与帧内值）；i += 1（重同步）
```

要点：
- **L=整帧总长** 使粘包/断帧判定天然简单（L<已收=粘包，L>已收=未收完）；
- CS 失败帧单独归入异常帧并给出具体原因，不与有效帧混淆；
- 噪声字节只影响帧间偏移，68/长度/16/CS 四重校验保证帧内容不会被噪声污染；
- 时间戳/注释文本先经 `textutil.extract_bytes` 清洗（0x 前缀、`68H` 后缀、日期时间、注释符），残余伪 hex 字节位于帧外，由上述校验自动排除。

## 3. 信息域 R 位定义

**下行（DIR=0，表 4）**：

| 字节 | D7~D4 | D3 | D2 | D1 | D0 |
|---|---|---|---|---|---|
| R1 | 中继级别(0~15) | 冲突检测 | 通信模块标识 | 附属节点标识 | 路由标识 |
| R2 | 纠错编码标识(0=未编码,1=RS) | | 信道标识(0~15) | | |
| R3 | 预计应答字节数（BIN，0=默认延时） | | | | |
| R4~R5 | 通信速率（D14~D0，BIN）+ D15 速率单位标识（0=bit/s，1=kbit/s） | | | | |
| R6 | 报文序列号（0~255 循环） | | | | |

**上行（DIR=1，表 5）**：

| 字节 | D7~D4 | D3~D0 |
|---|---|---|
| R1 | 中继级别 | D3=0，D2=通信模块标识，D1=0，D0=路由标识 |
| R2 | 0 | 信道标识 |
| R3 | 电能表通道特征 | 实测相线标识（0=不确定，1~3=第1~3相） |
| R4 | 末级应答信号品质（0~15） | 末级命令信号品质（0~15） |
| R5 | 预留 | D0=事件标志 |
| R6 | 报文序列号 | |

**注意**：376.2 没有帧序域 SEQ（那是 376.1 概念）；请求/应答配对依靠 R6 报文序列号 + AFN=00H 确认/否认。

## 4. AFN 与 Fn

| AFN | 名称 | 主要 Fn |
|---|---|---|
| 00H | 确认/否认 | F1 确认；F2 否认（错误状态字） |
| 01H | 初始化 | F1 硬件初始化；F2 参数区初始化；F3 数据区初始化 |
| 02H | 数据转发 | F1 转发通信协议数据帧（内嵌 645/698） |
| 03H | 查询数据 | F1 厂商代码和版本信息、F2 噪声值、F4 主节点地址等 |
| 04H | 链路接口检测 | F1 发送测试；F2 从节点点名；F3 报文通信测试 |
| 05H | 控制命令 | F1 设置主节点地址、F3 启动广播、F200 拒绝节点上报等 |
| 06H | 主动上报 | F1 上报从节点信息；F2 上报抄读数据；F3 上报路由工况变动 |
| 10H~15H | 路由查询/设置/控制/数据转发/数据抄读/文件传输 | 见调研笔记 §2.7 |
| F0H | 内部调试 | 厂家自定义 |
| F1H | 并发抄表 | F1 集中器主动并发抄表（内嵌 645/698） |

**Fn 数据单元定界**：工具维护"已知 Fn 数据单元长度表"（见 `applayer._DECODERS`），DT1 多位同时置 1 时按位序逐个解析；未知 Fn 或长度不确定时以 HEX 转储兜底并注明，不臆造解析。

## 5. 已实现的数据单元解码（applayer.py）

| AFN/Fn | 格式 | 处理 |
|---|---|---|
| 00H F1 | 4B 信道状态 BS + 2B 等待时间(s) | 逐位/数值解读 |
| 00H F2 | 1B 错误状态字 | 16 种中文错误码（通信超时/无效数据单元/…/正在抄读该表） |
| 02H F1 | 1B 协议类型 + 1B 长度 + 内容 | 类型 01/02 → **内嵌 645 结构解析**；03 → HEX 并注明 698.45 |
| 03H F1(上) | 2B 厂商 ASCII + 2B 芯片 ASCII + 3B 版本日期 BCD + 1B 版本 | 解读+备注"常见布局" |
| 03H F2 | 1B（D3~D0 噪声强度） | 解读 |
| 04H F1(下) | 1B 持续时间(s) | 解读 |
| 04H F2 | 无数据单元 | 注明 |
| 04H F3(下) | 1B 信道+1B 速率+6B 目标地址+1B 协议+1B 长度+内容 | 解读+内嵌报文 |
| 06H F1(上) | 1B 数量 n + n×(6B 地址+1B 协议+2B 序号) | 逐从节点展开 |
| 06H F2(上) | 2B 序号+1B 协议+2B 上行时长(s)+1B 长度+内容 | **内嵌 645 结构解析** |
| 06H F3(上) | 1B 变动类型（1=抄表结束/2=搜表结束/3=台区识别结束） | 中文解读 |
| 14H F1(上) | 1B 相位+6B 从节点地址+2B 序号 | 解读 |
| 14H F3(上) | 6B 地址+2B 预计延迟(s)+1B 长度+内容 | 内嵌 645 |
| 14H F4 | 1B 数据项类型+4B 交采标识 | 解读 |
| F1H F1(下) | 1B 规约+2B 保留+2B 长度+内容 | 内嵌 645 |
| F1H F1(上) | 1B 规约+2B 长度+内容 | 长度 0 → **抄表失败**（A1=失败电表地址） |
| 其余 | — | HEX 转储 + 注明"暂未内置，可对照标准查阅" |

**内嵌 DL/T 645-2007 解析（six45.py）**：定位 `68 L 68 C A(6B BCD 低位在前) [DI+数据] CS 16`，CS 校验通过后解析控制码（读数据/应答/异常应答 C1~C7 错误字）、表通信地址（BCD 正序）、数据标识（内置常用 DI：9010 正向有功总电能、2021 A相电压、0400 日期时间等 20 项），作为子树挂载到宿主帧字段树。

## 6. 错误诊断策略

| 检查项 | 诊断输出 |
|---|---|
| 起始符 ≠ 68H / 结束符 ≠ 16H | 标记字段 error，帧校验列 ✗ |
| L ≠ 实际帧长 | "长度域 L=x 与实际帧长 y 不符" |
| CS 不符 | "CS 校验失败：计算 0xXX ≠ 帧内 0xYY"（字节图红框） |
| R1 声明有地址域但帧体不足 | "地址域长度超出帧范围" |
| DT1=0 | "未指明信息类 Fn" |
| 未知 AFN / Fn | 显示"备用/未定义(0xXX)"，不臆造 |
| 数据单元声明长度越界 | 记入 errors，按 HEX 展示 |
| 376.1 形态字节流 | 告警"疑似 376.1 帧"，不误解析 |

## 7. 与 376.1 的关键差异（辨误）

| 项 | 376.1 | 376.2 |
|---|---|---|
| 帧头 | 68 L L 68（双起始符） | **68 L（单起始符）** |
| L 语义 | 低 2 位规约标志，值=用户数据长度 | **整帧总长**，无标志位 |
| C 域 D5~D0 | FCB/FCV/功能码 | **通信方式** |
| SEQ | 有（PSEQ/CON/FIR/FIN/TPV） | **无**（用 R6 报文序列号） |
| 地址域 | 5 字节终端地址 | 0/12/18… 字节节点 MAC（BCD） |

用 376.1 解析器套 376.2 数据必然失败；工具在扫描阶段即按上述特征自动识别并提示。

## 8. 版本兼容与扩展点

- 通信方式 3 的文案按 2019 版显示"HPLC 载波通信"，备注 2013 版"宽带载波"；
- 预留通信方式 4（2024 版双模 HDC）与省级扩展 AFN（福建增补 50H~56H）的字典扩展点；
- 12 位 MAC 按帧内字节序展示（厂家显示习惯不一，待与目标厂家样例核对，已在调研笔记 §8 登记）；
- 新增 Fn 解码只需在 `applayer._DECODERS` 注册一行，UI 与导出自动生效。
